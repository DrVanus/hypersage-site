Your data in Fleet.

Your connected workspace

Fleet for Mac reads your App Store Connect portfolio directly from Apple using an API key you provide. It stores app details, release status, available reports, ratings and review excerpts, and dashboard snapshots on your Mac. Account setup metadata includes your workspace name, issuer ID, key ID, and optional vendor number.

Fleet stores its working copy of your private API key in this Mac’s Keychain. It uses the key to create short-lived authentication tokens for Apple. The private key is not included in those requests or in exported workspace files. Importing the key does not remove the original .p8 file; protect that original wherever you keep it.

The own-account connection does not upload your portfolio or private key to a Fleet-operated service. Apple receives the requests needed to supply your data and applies its own service policies. Normal refresh reads available reports. Choosing Enable analytics reports explicitly asks Apple to create ongoing analytics report requests.

Shared files & saved reports

Choosing Share workspace… saves a .fleetworkspace snapshot to a location you select. It can include commercially sensitive app information, metrics, and review excerpts. It does not contain your private API key or authentication tokens.

A workspace is a JSON file. Fleet does not add password encryption to it. Storage, delivery, access controls, and version history depend on your device and file provider. Anyone who receives a copy can read the included reports.

Fleet updates the selected file after successful Mac refreshes. iCloud Drive or another provider delivers it to your other devices. The receiving app reads that file and keeps a local dashboard for offline use. File delivery, background execution, and widget updates are scheduled by the provider and operating system; updates are not guaranteed to be immediate.

On iPhone and iPad, Fleet keeps the selected file’s access bookmark locally. A compact active-workspace summary is stored in shared Keychain storage for the app and widget. The widget displays saved data and does not receive your App Store Connect private key.

Notifications & app diagnostics

Release notifications are optional. Fleet creates local notifications from changes it discovers in the selected data. Enabling them does not create a Fleet push-service account. You can manage permission in system Settings; timing depends on when Fleet receives and reads updated data.

The Fleet own-account apps include no advertising or third-party analytics SDK, and they do not upload Fleet telemetry. Information you choose to send by email is handled separately, as described under Support correspondence.

Disconnecting & keeping copies

Disconnecting an account on the Mac removes Fleet’s stored private key and stops future automatic refresh for that connection. The saved workspace and reports remain on the Mac.

This does not revoke the API key at Apple or remove your original key file, shared exports, other devices’ copies, or provider backups. Revoke the key in App Store Connect if you want to invalidate it at its source.

Disconnecting a workspace on iPhone or iPad clears the active connection and widget summary and removes the selected dashboard cache and bookmark where available. It does not delete the original file in Files, the Mac’s data, or copies held elsewhere. Provider backups and version histories follow that provider’s controls.

Website & existing hosted connections

Previously configured internal users may retain a separate hosted connection to hypersage.ai/fleet/. It downloads a prepared dashboard over HTTPS and uses a locally saved dashboard passphrase. That passphrase may be stored in the app’s website storage and shared Keychain. It is different from an App Store Connect private key. Disconnecting a workspace does not promise removal of all legacy website storage or credentials.

These support and privacy pages, and the existing hosted Fleet route, are served through GitHub Pages. Hosting requests disclose ordinary network information, including your IP address, to GitHub under its privacy practices. The HyperSage website privacy policy describes this hosting and links to GitHub’s privacy policy.

The Fleet route does not use HyperSage’s page-view counter. These support and privacy pages contain no forms, scripts, or external analytics. Hosting requests still occur when you visit them; the own-account app’s storage description does not mean that website visits disclose no information.

Support correspondence

If you email support@hypersage.ai, HyperSage receives your email address and the information you include. Support correspondence is retained as long as needed to address the issue.

Do not send private .p8 keys, authentication tokens, passphrases, or unredacted workspace files. You can ask about Fleet’s data handling through the same address. For troubleshooting guidance, visit Fleet support.

Fleet 1.3 for Mac

For Apple silicon Macs running macOS 14 or later.

Download Fleet 1.3 for Mac

  1. Unzip the download. Open the downloaded ZIP file in Finder to extract Fleet.
  2. Move Fleet to Applications. Drag the Fleet app into your Applications folder.
  3. Open Fleet. Launch it from Applications, then connect your own App Store Connect account using the steps below.

Connect your account

  1. Start on your Mac. Connect your own App Store Connect account using its issuer ID, key ID, and private .p8 key. Choose a key with access to the apps and reports you need. Fleet keeps its working copy in your Mac’s Keychain; keep the original file secure.
  2. Let your portfolio load. The app list may appear before all reports are available. If you need ongoing analytics reports, choose Enable analytics reports in Workspace settings. Requesting them requires an Admin API key and is separate from normal refresh. Apple prepares the reports after access is enabled.
  3. Try the demo if you prefer. It contains clearly labeled synthetic data and does not require an API key.

What you need

Fleet supports Apple silicon Macs running macOS 14 or later, and iPhone or iPad running iOS or iPadOS 17 or later. Live reporting starts with Fleet for Mac and your own App Store Connect account. Shared-workspace devices display the saved reports.

Share with your devices

On the connected Mac, choose Share workspace… and save the .fleetworkspace file in a private iCloud Drive folder or another file provider accessible from your devices.

On iPhone or iPad, choose Open workspace and select that file in Files. On another Mac, choose Open shared workspace…. Those devices do not receive your App Store Connect private key.

A shared workspace contains your portfolio and reports. It is a readable JSON file, and Fleet does not password-encrypt it. Keep it in a private folder and share it only with people who should see the included data.

Keep reports current

Keep Fleet running on the connected Mac, with the Mac awake and online. Fleet fetches available reports and updates the selected shared file after successful refreshes. Your file provider then delivers that file to the other devices.

Opening Fleet on your phone checks the selected workspace. Background checks and widget updates follow your provider’s and Apple’s scheduling, so they may arrive later.

If another device shows older reports

  1. Check the displayed report dates on the connected Mac and whether its latest connection completed.
  2. Check that the shared file has finished uploading or downloading in Files. A separate copy saved only On My iPhone will not receive the Mac’s changes.
  3. Open Fleet on the receiving device. If the file was moved or replaced, use Choose another workspace to select the correct file. On the Mac, choose Share workspace… again if its export location changed.

When a report or file is temporarily unavailable, Fleet keeps the last available dashboard. The report date describes the data; opening the app does not make an older report current. A widget can update after the app.

Understand missing figures

Apple can make the app list available before analytics reports are ready. Reading reports and managing report requests require the appropriate App Store Connect permissions. See Apple’s analytics report documentation for availability and access requirements.

Fleet keeps an unavailable figure distinct from a measured zero. USD proceeds use Apple’s analytics estimates; Fleet does not relabel another settlement currency as dollars. Reporting periods, available report types, and Apple’s processing can explain differences from other App Store Connect views.

An optional vendor number enables the corresponding sales-report path where your account is authorized to use it.

Notifications & disconnecting

Release notifications are optional and local. On your phone, choose Enable release notifications in settings to request permission. A notification can appear only after Fleet reads a relevant change. Use Open notification settings to manage permission.

Disconnecting an account on the Mac removes Fleet’s Keychain copy of its private key and stops future automatic refresh for that connection. Saved reports remain. Disconnecting on the phone clears its active file connection, dashboard cache where available, and widget source.

Disconnecting does not remove the original shared file, the original .p8 file, other devices’ copies, or provider backups. It does not revoke the API key at Apple. Revoke a key in App Store Connect and use your file provider’s controls to remove shared copies.

Already using a hosted Fleet connection?

Use existing hosted connection is for previously configured internal installations. It uses a separate dashboard and passphrase. New customers should connect their own App Store Connect account on the Mac. Read about this mode in Fleet privacy.
